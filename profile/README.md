# rds9

rds9.net を基盤とする開発チーム。

## 私たちについて

rds9 は、プロジェクトとしての完成度を個人開発ではできないレベルまで高めるために結成された開発チームです。

AI ツールを開発に組み込むことを前提としますが
中身のない AI の出力をコピペしたような成果物は必要ありません。コードを開発者がレビューできるくらいの知識は絶対条件としています。

## プロジェクト

| プロジェクト | 概要 |
|--------------|------|
| **ゆれログ** | 「揺れた！」をリアルタイムで共有・通知する Discord Bot |
| **世界大戦bot** | 領土シミュレーション・世界地図リアルタイム生成 Bot |
| **まきぐもぼっと** | AI チャット機能を搭載した Discord Bot |

※随時更新予定

## チーム構成

| チーム | 役割 |
|--------|------|
| **Core** | 全体設計・レビュー |
| **Dev** | 開発部（Bot・Web・インフラ） |
| **Planner** | 企画部（アイデア・仕様策定） |
| **Promoter** | 広報部（宣伝・SNS運用） |
