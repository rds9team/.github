l# rds9

rds9.net を基盤とする開発チーム。

## チームについて

年齢や肩書きは一切不問。純粋な技術力と美学のみで評価する開発チームです。

AIツールを開発プロセスに組み込むことは前提としながらも、中身のないAIコピペ成果物は排除します。コードの1行1行に、開発者自身の意図と基礎技術の理解が宿っていることを絶対条件としています。

## プロジェクト

| プロジェクト | 概要 |
|--------------|------|
| ゆれログ | 地震情報をリアルタイムで共有・通知するDiscord Bot |
| 世界大戦bot | 領土シミュレーション・世界地図リアルタイム生成Bot |
| まきぐもぼっと | AIチャット機能を搭載したDiscord Bot |
| rds9.net | チームのポートフォリオ・サービス群 |

## チーム構成

| 部門 | 役割 |
|------|------|
| 開発部 | Bot・Web・インフラの開発 |
| 企画部 | アイデア・仕様策定 |
| 広報部 | 宣伝・SNS運用 |

## 参加について

コードが書けなくても問題ありません。想像力豊かで面白いアイデアが出せる人、企画が得意な人も歓迎します。

応募はDiscordサーバーのチケットから。エントリーシートが自動発行されます。
