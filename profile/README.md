## rds9teamとは

rds9teamは、rds9ブランドのもとで以下のサービスを開発・運用するチームです。

- Discord Bot
- Webサイト
- API
- Webホスティング
- サーバー・インフラ運用
- 保守・移管・パブリッシング
- チーム向け開発支援

AIやクラウドサービスを活用しながら、機能性・安全性・保守性を重視したサービス提供を行います。

[![Join Team](https://img.shields.io/badge/rds9team-Join_Us-blue?style=for-the-badge)](https://team.rds9.net)

## 主な方針

- 安全かつ継続的にサービスを運用する
- Issue・Pull Requestを中心に共同開発する
- 本番環境と秘密情報を適切に管理する
- AIの出力を理解・検証したうえで利用する
- UI/UX、アクセシビリティ、保守性を重視する
- メンバーの技術力や実績を可視化する

## サービス

現在、以下のサービスを提供・開発しています。

- Discord Botの開発・運用
- Botの保守・機能追加
- Webページ制作
- 静的・動的Webホスティング
- アプリケーション実行環境
- Discordサーバー設定
- サーバーバックアップ・リストア
- Bot移管・パブリッシング

料金や対応範囲については、[料金表](./docs/services.md)を確認してください。

## 開発への参加

開発に参加する場合は、以下を確認してください。

1. [運用仕様書](./spec.md)を読む
2. 担当するIssueを確認する
3. `dev`ブランチから作業ブランチを作成する
4. 実装・テストを行う
5. Pull Requestを作成する
6. レビュー後にマージする

ブランチ名やコミットメッセージなどのルールは、運用仕様書に定めています。

## セキュリティ

APIキー、Botトークン、パスワード、秘密鍵、`.env`ファイルなどの秘密情報を、リポジトリやIssue、Pull Requestへ投稿しないでください。

脆弱性や秘密情報の漏洩を発見した場合は、公開Issueではなく管理者へ直接報告してください。

詳細は[セキュリティガイド](./docs/security.md)を確認してください。

## ライセンス

このリポジトリのライセンスおよび各プロジェクトの利用条件は、プロジェクトごとに定めます。

無断転載、無断利用、無許可での再配布は行わないでください。
