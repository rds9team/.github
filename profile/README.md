# rds9

rds9.net を基盤とする開発チーム。

## 私たちについて

rds9 は、個人開発の限界を突破し、プロダクトとしての完成度を極限まで高めるために結成された開発チームです。

AI ツールを開発プロセスに 120% 組み込むことを前提としながらも、中身のない AI コピペ成果物は必要ありません。コードに、開発者の基礎技術の理解が宿っていることを絶対条件としています。

## プロジェクト

| プロジェクト | 概要 |
|--------------|------|
| **ゆれログ** | 「揺れた！」をリアルタイムで共有・通知する Discord Bot |
| **世界大戦bot** | 領土シミュレーション・世界地図リアルタイム生成 Bot |
| **まきぐもぼっと** | AI チャット機能を搭載した Discord Bot |

※随時更新予定

## チーム構成

| チーム | 役割 |
|--------|------|
| **Core** | 全体設計・レビュー |
| **Dev** | 開発部（Bot・Web・インフラ） |
| **Planner** | 企画部（アイデア・仕様策定） |
| **Promoter** | 広報部（宣伝・SNS運用） |
